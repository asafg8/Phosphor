phosphor scan bundle PHP: self-built static PHP 8.5.12 CLI (+ gh-24488 fix), amd64 + arm64. Built 2026-10-26.

Why: a php2shell remediation tool must not ship a pre-php2shell PHP, even as a local-only scanner. static-php.dev's
newest 8.5 build is 8.5.8 (pre-fix), so we build 8.5.12 ourselves.

No network, database or crypto extensions.

Build: docker run --rm --platform linux/<arm64|amd64> -v src/scanbundle/php:/s:ro -v OUT:/out alpine:3.20 \
         sh /s/build.sh <spc asset> <spc sha256>        (arm64 native 161 s; amd64 under emulation 446 s)
build.sh checks every input sha256, applies the patch, verifies php -v = 8.5.12, runs the GH-24488 reproduction
(must print "gh24488-repro ok"), and packs the binary as a single file "php" with a deterministic tar header.
